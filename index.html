Features

Flexible Features

Native ruby annotations, flexible engine options, and dynamic DOM support.

Three Reading Formats

Switch between hiragana, katakana, and romaji without changing the original Japanese text.

Kana-Anchor Alignment

Keeps okurigana outside ruby where possible, with optional per-kanji dictionary alignment.

Reading Overrides

Set shared readings or correct individual occurrences with data-ym. Local readings take priority.

Precise Language Scoping

Target Japanese with <ja> or lang="ja", and exclude any subtree.

DOM Mutation Observer

Annotate new content and respond to text, language, and reading changes with observe().

Clean Plain-Text Copying

Copy original text, displayed readings, or both—without unwanted ruby markup.

Accessible Markup

Keeps original text available to assistive technology while hiding generated readings. Broader screen-reader testing is pending.

Two Engine Options

Choose lightweight Suzume, morphological Kuromoji, or your own reading provider.

Online & Offline

Processes text locally in hosted workers or standalone offline scripts. No remote reading API.

Quickstart

Basic setup

Host src/ and vendor/ together over HTTP(S), then include the stylesheet and annotate a Japanese container.

index.html Docs ↗ 
<!-- 1. Include default ruby styles -->
<link rel="stylesheet" href="./src/yomigana.css">

<!-- 2. Mark Japanese content with lang="ja" -->
<article id="story" lang="ja">
  公園の桜が咲きます。朝の空気は少し冷たく、川の水は静かに流れていました。
</article>

<!-- 3. Annotate with vanilla JavaScript -->
<script type="module">
  import { yomigana } from './src/index.js';

  const reader = new yomigana({ root: '#story' });
  await reader.annotate();
  reader.observe(); // Watches for dynamic DOM changes
</script>
Architecture

Pipeline

Text flow from DOM text nodes to ruby elements.

01. Extract

DOM Traversal

A TreeWalker scans eligible text nodes while checking lang="ja" and ignoring excluded elements or [data-yomigana-ignore].

02. Tokenize

Local Analysis

Suzume WebAssembly or Kuromoji segments Japanese text. The playground and demos support switching between both engines.

03. Resolve

Readings

Suzume tokens use JMdict lookup and supported inflections. Kuromoji supplies readings directly from its analysis.

04. Align & Inject

Ruby Generation

Aligns kana to kanji using kana-anchoring (or per-kanji dictionary records) and inserts native <ruby> elements.
