春川の音。花の色。
何も急がない、一日。KYOTO / APRIL

日本では、春になると桜が咲きます。今日は友人と一緒に、京都の鴨川を歩きました。朝の空気は少し冷たく、川の水は静かに流れていました。

足を止めると、見えてくるもの

橋を渡ると、小さな公園がありました。桜の木の下で、子供たちが遊んでいます。私たちは温かいお茶を飲みながら、しばらく花を眺めました。

「きれいだね」と友人が言いました。忙しい毎日の中では、こんなにゆっくり空を見上げることも忘れてしまいます。

目的地に着くことよりも、
途中の景色を楽しむ日があってもいい。

路地の喫茶店で、一休み

昼ご飯の後、古い喫茶店に入りました。店の名前は「木漏れ日」。窓の向こうには、赤い自転車と白い猫が見えます。

私は本を読み、友人は手紙を書きました。難しい言葉があっても、読み方が分かると、文章を読むのが少し楽になります。

明日はどこへ行こう。そんなことを考えながら、帰り道で大人も子供も笑っている姿を見ました。何気ない一日が、心に残る旅になりました。

開発者向け：使い方とテスト項目

This online showcase analyzes text in a Web Worker. Kuromoji + IPADIC is the default; Suzume + JMdict is the lightweight alternative. Only the selected engine's assets load. No reading API is used. Optional JmdictFurigana data provides per-kanji grouping for exact matches; otherwise kana-anchor alignment is used. Readings can be incorrect in context.

Kuromoji: IPADIC notice. Change defaultEngine in yomigana-setup.js to configure this demo.

Dictionary data: JMdict, converted by jmdict-simplified (CC BY-SA 4.0). Optional alignments: JmdictFurigana. Data notices.

import { yomigana, createLocalProvider } from '../src/index.js';
const provider = createLocalProvider({ engine: 'kuromoji' });
const reader = new yomigana({ root: 'article', provider });
await reader.annotate();
reader.observe();

Test links, bold text, dynamic notes, existing ruby, the size slider and this unannotated code block. The library skips controls and editable content. Text split across inline elements is analyzed separately in this first version.

Language filtering is enabled by default: <ja> or inherited lang="ja" or ja-JP is required. Unmarked text is skipped unless assumeJapanese: true is explicitly set. Use data-yomigana-ignore to exclude a subtree. observe() responds to new content, language changes, exclusion/visibility attributes, data-ym changes and edits to generated ruby base text. CSS-only visibility changes are not observed.
